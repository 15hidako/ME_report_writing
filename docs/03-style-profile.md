# 文体プロファイル + 隠語辞書

生成プロンプトに埋め込む文体定義。ソース: 過去記事「天界のスパ えりか」1本 +
今後の投稿での修正差分を取り込んで育てる(修正が入ったらこのファイルを更新)。

## 文体の特徴(過去記事から抽出)

1. **です・ます基調 + 体言止めの混合**。「指圧からスタート。」「BK確定。」のように
   展開の節目は体言止めで畳みかける
2. **1文が短い**。1段落2〜3文まで。`<br />` で細かく改行しテンポを作る
3. **隠語は伏せ字アルファベット**(下記辞書)。露骨な直接表現は使わない
4. **数値・事実を具体的に**: オプション体系(4K・5K・6K)、選択コース、カップ数
5. **正直な減点も書く**(「盛ってる疑惑」「ガードやや堅め」)→ 信頼性の源泉
6. **締めは定型**: 「皆さまのご武運をお祈りいたします!」
7. 絵文字はほぼ使わない(♡を稀に)。過剰な「!」連打はしない

## 追加する要素(競合分析に基づく強化・2026-07決定)

8. **セリフ⇔心の声の往復**: 彼女の一言「」+ 語り手の内心(括弧書きツッコミ)。
   1記事に2〜3往復。メンエス人気レポートの臨場感の核
9. **クリフハンガー**: 無料部分はオイル投入直前の「空気が変わる一文」で切る
10. **煽りすぎない**: タイトルはフック型にするが、本文はあくまで実体験の淡々とした
    熱量で書く(誇張は★評価との矛盾を生み、レビューを下げる)

## AIっぽさ除去チェックリスト(生成時に適用)

- 「〜と言えるでしょう」「〜こと間違いなしです」等の断定回避表現を使わない
- 全段落が同じ長さ・同じリズムにならない(短い段落を混ぜる)
- 「まとめると」「いかがでしたか」を使わない
- 形容詞の三連(「優しくて、丁寧で、素敵な」)を避ける
- 体験していないことを補完して書かない。質問票にない描写は生成しない
  (事実の水増しは規約2-1の証跡提出リスクと購入者レビュー低下に直結)
