# 質問票設計

設計原則: **訪問直後に片手・5分以内**で完了できること。
自由記述は最小限(合計5欄程度)、それ以外はタップ選択。
入力途中の自動保存(localStorage)必須。後から追記・編集できる。

セクションA(基本情報)は予約時点で事前入力しておける想定。
訪問直後に入力するのは B〜E のみ。

## セクションA: 基本情報(事前入力可)

| 項目 | 形式 | 備考 |
|---|---|---|
| 訪問日時 | 日付+時間帯選択 | デフォルト今日 |
| 都道府県 | 選択 | wakustカテゴリーに対応 |
| エリア(駅) | テキスト | タグ兼用(例: 恵比寿・中目黒) |
| 店名 | テキスト | 有料部でのみ開示 |
| 店URL | テキスト | |
| セラピスト名 | テキスト | 有料部でのみ開示 |
| セラピストprofile URL | テキスト | |
| X(Twitter) URL | テキスト | 任意 |
| 公称/推定年齢 | 数値+推定フラグ | |
| コース(時間・料金) | テキスト+数値 | 例: 80分 18,000円 |
| オプション体系 | テキスト | 例: 3種類(4K・5K・6K) |
| 選択したオプション | テキスト | 例: 6K |
| 指名料 | 数値 | 任意 |
| 部屋タイプ | 選択: マンション型/ルーム型/その他 | ※マンション名・階数・部屋番号は規約2-6で記載禁止のため**収集しない** |
| 予約方法 | 選択: X DM/LINE/電話/Web | |
| 証跡チェック | チェックボックス | 「予約スクショを保存した」(規約2-1の提出要求対策) |

## セクションB: 評価6軸(★1〜5 + 一言)

各軸: 星タップ + 一言コメント(20〜60字目安、音声入力推奨)。

1. 顔
2. スタイル
3. 接客
4. マッサージ技術
5. エロ施術
6. 寛容度

一言コメントはそのまま記事の評価セクションに流し込まれるため、
「★の理由」を書く(例: 「圧強めでしっかり効く」「ガードやや堅め、ロック箇所固定」)。

## セクションC: スペック/タグ(チップ選択)

複数選択チップ。**選んだものがそのまま wakust タグ候補+タイトル素材になる。**

- 系統: ギャル / 清楚 / お姉さん / 妹系 / 熟女 / モデル系 / 元気系 / クール
- 体型: 小柄 / スレンダー / ムチムチ / グラマー / 長身
- 胸: カップ推定(A〜J選択) + 実感コメント選択(見た目通り / 盛ってる疑惑 / 期待以上)
- 特記: 元メンエス経験者 / 新人 / 入店したて / タトゥー / ネイル / 日焼け
- 自由タグ: テキスト(コンマ区切り)

## セクションD: 施術フロー(フェーズ別)

各フェーズ: 定番要素のチェックボックス + ハイライトメモ(任意・1行)。
チェック項目は隠語辞書(03-style-profile.md)と連動。

| フェーズ | チェック項目例 |
|---|---|
| 対面〜シャワー | KP装着 / バスローブ / 私服対面 / 会話が弾んだ |
| うつ伏せ前半 | 指圧 / パウダー / 圧強め / 圧弱め / 密着あり |
| オイル〜SP展開 | SPPN / MB等衣装 / カエル足 / TMアプローチ / BK / キワ攻め(KWKW) |
| 仰向け | 上半身ケア / またがり / ロック / 絶景 |
| クライマックス | HJ / 体勢(自由記述) / SKR / 回数 / 発展の気配 |
| その後 | シャワー / 会話 / 次回営業トーク |

- 全体ハイライト: 「一番良かった瞬間」自由記述(1〜2文)【重要・必須】
- 残念ポイント: 自由記述(任意) — 正直な記述が信頼を作る

## セクションE: 臨場感素材【差別化の核】

生成記事に「セリフ⇔心の声」の往復を作るための素材。

| 項目 | 形式 | 例 |
|---|---|---|
| 彼女のセリフ | テキスト×2〜3 | 「気持ちいいですか〜♡」 |
| 心の声・ツッコミ | テキスト×1〜2 | (今は聞かないでくれ…) |
| タイトル用フック一言 | テキスト×1 | 「元メンエス経験者のKWKWテクがヤバい」 |
| 総評・リピート意向 | 選択: リピ確 / あり / なし / 微妙 | |

## セクションF: 販売設定

| 項目 | 形式 |
|---|---|
| 販売ポイント案 | 数値(デフォルト100〜300、シリーズ実績で引き上げ) |
| シリーズ通し番号 | 自動採番(訪問レコード数から) |
| 記事タイプ | 選択: 単体体験談 / 再訪(初回レコードを選択) |

## 入力時間の見積もり

- A: 事前入力済み(予約時に2分)
- B: 星6回+一言6個 ≒ 2分(音声入力)
- C: チップタップ ≒ 30秒
- D: チェック+メモ ≒ 1.5分
- E: セリフ・フック ≒ 1分
- 合計(訪問直後): **約5分**
