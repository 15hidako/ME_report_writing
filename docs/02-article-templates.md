# 記事テンプレート4系統

wakust 投稿フォームは無料部分・有料部分ともに HTML ソース編集可。
使用タグ: `<h3>` `<p>` `<ul><li>` `<a>` `<strong>` `<em>` `<small>` `<span style>` `<br />`

共通ルール:
- 店名・源氏名・リンクは**有料部分でのみ**開示(単体体験談・再訪の場合)。名前公開版を選んだ記事は、店名と源氏名を無料部分とタイトルにも出し、リンクだけを有料部分に置く(2026-11-10 本人指示)
- マンション名・階数・部屋番号は書かない(規約2-6)
- 年齢・身長・体型・カップ数は、タイトル・タグ・サムネイルを含む無料部分に書かず、有料部分に回す。これだけでセラピストが推測できるため。タトゥーも訴求にならないので無料部分に出さない(2026-11-11 本人指示)
- 有料部分はテキストで完結させる。リンクには必ず内容併記(規約1-5, 1-6)
- 無料部分に「有料部分に何があるか」を必ず書く(規約2-5)

## タイトル公式

```
【フック】+ 属性キーワード + 展開の匂わせ +【メンズエステ体験談】
```

- フック例: 【元メンエス経験者】【圧強テク】

2026-11-11変更(本人指示。[H-15](15-requirements-history.md#h-15-タイトル先頭のエリアと在籍確認)): 単体体験談と再訪記事は、先頭の【】をエリアと出勤確認の月にする。体験内容起点の記事では地名がいちばんのフックになるため。

```
【エリア｜M月出勤確認】+ フック + 属性キーワード + 展開の匂わせ +【メンズエステ体験談】
```

- 出勤確認日がない記事は【エリア】だけにする。在籍より確度が高いため、HPに名前があることではなく、出勤表で出勤を確かめた日を使う。月までにとどめ、日付や出勤予定日は入れない
- フックは【】で囲まず、先頭の直後に短く置く(例: 元メンエス経験者の、ドMセラピストに)
- 例: `【恵比寿｜11月出勤確認】元メンエス経験者のギャルの圧強KWKWテクでSKR不可避【メンズエステ体験談】`
- まとめ記事は従来の【フック】で始める型のまま
- 販売部数や売上、収益といった販売実績は、タイトルにも本文にも入れない(2026-11-10 本人指示)
- 属性: セクションCのチップ(系統・特記)から2〜3個。体型・カップ数・年齢・タトゥーは使わない
- 展開の匂わせ: SKR不可避 / まさかの展開 / ○○モード突入 など
- 店名・源氏名はタイトルに**入れない**(エリアは入れてよい)。名前公開版では入れる
- 例: `【元メンエス経験者】恵比寿のギャルの圧強KWKWテクでSKR不可避【メンズエステ体験談】`
- 本番系の結果(NS、NN、2回戦など)は、訪問記録に体験の事実がある場合に限り、タイトルの展開の匂わせに使ってよい。記録にない結果や、可能性の示唆だけでタイトルに入れない(2026-11-11 本人指示。[H-14](15-requirements-history.md#h-14-本番系の結果をタイトルに出す))
- 通し番号(#N)は本人のPC上の管理用。タイトル、本文、リンク文、サムネイルなど投稿物には一切載せない(2026-11-11 本人指示。サムネイルの U-13 と同じ扱い)

タグ(コンマ区切り): `メンズエステ, {エリア駅}, {都道府県}, {系統チップ}, {特記チップ}`

2026-11-10追記: wakustのタグは最大6個で、本文と無関係なタグは規約違反になる。「東京都」「神奈川県」などの都道府県名と「メンエス」はNGタグで入力できない。`{都道府県}`は投稿時に外すか、「県」などを省いた地域名にする。アプリが出すタグ候補には、まだ都道府県名が入っている([残件C1](11-remaining-tasks.md#規約再確認で残ったコード側の作業2026-11-10))。

2026-11-11追記: `{都道府県}`は外さず、「都」「府」「県」を省いた地域名で入れる(例: 東京、神奈川)。正式名の「東京都」「神奈川県」は入力できないため使わない(本人指示。[H-07](15-requirements-history.md#h-07-タグの個数とngタグ))。

## 1. 単体体験談(本体)

### 無料部分

```html
<p>{導入フック 1〜2文。エリア+系統+展開で釣る。店名は出さない}</p>

<h3>今回のセラピスト</h3>
<ul>
<li>エリア: {エリア}</li>
<li>系統: {チップから}、{特記 例: 黒髪ショート}</li>
<li>料金: 計{コース代+指名料+オプション代}円</li>
</ul>

<h3>こんな方にお勧め</h3>
<ul>
<li>{系統}系が好きな方</li>
<li>{施術の特徴 例: 圧強め・キワ攻め}が好きな方</li>
</ul>

<h3>体験のダイジェスト</h3>
<p>{ご対面の要所。記録にあるセリフを1つ}</p>
<p>{施術から展開が動いた所。語り手の反応を添える}</p>
<p>{クライマックスとその結果まで。体位や細部は本編に残す}</p>

<h3>有料部分の内容</h3>
<ul>
<li>店名・セラピスト名(HP/Xリンク付き)、年齢と体型</li>
<li>コース・オプションの実額</li>
<li>評価6軸(顔/スタイル/接客/マッサージ技術/過激施術/寛容度)</li>
<li>ご対面から最後までの全展開</li>
<li>{記録がある場合だけ: 今回の進め方}</li>
<li>総評と残念ポイント</li>
</ul>
<p><small>※本記事の内容は筆者の個人的な体験に基づくものであり、同様の体験を保証するものではありません。</small></p>
```

無料部分の原則: **展開の要所をクライマックスの結果まで要約して見せ、名前と全貌を有料部分で売る**(2026-11-11 本人指示)。施術の前半で切らない。ダイジェストは1〜2文の段落を時系列に並べ、体位・細部の流れ・彼女の反応の詳細は本編に残す。以前の「オイル投入の直前で切る」型からの変更点と理由は [H-12](15-requirements-history.md#h-12-無料部分の切り方) にある。

### 有料部分

```html
<h3>店舗・セラピスト情報</h3>
<p>店舗: <a href="{店URL}">{店名}</a>({店URL})</p>
<p>セラピスト: {源氏名}</p>
<p>店舗HP: <a href="{profileURL}">{profileURL}</a></p>
<p>X: <a href="{xURL}">{xURL}</a></p>
<p>出勤確認: {YYYY年M月上旬/中旬/下旬}に店舗HPの出勤表で確認済</p>
<p>プロフィール: {年齢}歳 / {身長}cm / {カップ}カップ / {体型}</p>
<p>コース: {時間・料金} / オプション: {体系}(今回は{選択}を選択)</p>

<h3>評価</h3>
<ul>
<li><strong>顔:</strong>{★}<br />{一言}</li>
<li><strong>スタイル:</strong>{★}<br />{一言}</li>
<li><strong>接客:</strong>{★}<br />{一言}</li>
<li><strong>マッサージ技術:</strong>{★}<br />{一言}</li>
<li><strong>過激施術:</strong>{★}<br />{一言}</li>
<li><strong>寛容度:</strong>{★}<br />{一言}</li>
</ul>

<h3>ご対面</h3>
<p>{対面〜シャワー。セリフ⇔心の声の往復}</p>

<h3>施術スタート(うつ伏せ)</h3>
<p>{うつ伏せ}</p>

<h3>オイル投入から{展開}へ</h3>
<p>{フェーズD: オイル〜SP展開。セリフ⇔心の声の往復}</p>

<h3>仰向けへ</h3>
<p>{フェーズD: 仰向け}</p>

<h3>クライマックス</h3>
<p>{フェーズD: クライマックス+全体ハイライト}</p>

<h3>今回の進め方</h3>
<p>{記録がある場合だけ。本人がした声のかけ方、断られたこと、気をつけたこと}</p>

<h3>総評</h3>
<p>{体験内容起点: 良かった点を中心に。残念ポイントは短く。リピート意向は書かない}</p>
<p>{セラピスト起点: リピート意向+残念ポイントも正直に}</p>
<p><em>皆さまのご武運をお祈りいたします!</em></p>
```

2026-11-11追記(本人了承。[H-13](15-requirements-history.md#h-13-体験内容起点型の記事から取り入れた点)):
- 「今回の進め方」は、結果に至るまでに本人がしたこと・避けたことを、記録にある範囲で書く。体験内容起点型の売れ筋記事で有料部分に厚みがあったのは、この種の情報だった。記録がなければ見出しごと省き、一般論の助言や記録にない攻略法を足さない。
- 「出勤確認」は、本人が投稿前に店舗HPの出勤表で出勤を確かめた日を書く(2026-11-11、在籍確認から変更)。確かめていなければ行ごと省く。出勤予定日をタイトルや無料部分に入れる型は、エリアと日付からセラピストを絞り込めるため使わない。

2026-11-13追記(本人指示。[H-16](15-requirements-history.md#h-16-記事5の手直しから統一した定型)):
- 評価軸の「エロ施術」は「過激施術」に改名した。記事の無料部分と有料部分だけでなく、質問票やボードの表示も同じ名前にする。
- 今回のセラピストの「特記」は独立した行にせず、系統の行に「、」でつなぐ。料金の合計は「料金: 計X円」の行で添える。コース代が分からなければ、この行を省く。
- 出勤確認では日付を出さず、上旬・中旬・下旬までにぼかす。末尾は「確認済」にする。
- 総評は記事の型で書き分ける。体験内容起点(通常版)では良かった点を中心に書き、残念ポイントは短く添えるだけにして、リピート意向は書かない。最後の加減は本人がボードで直す。セラピスト起点(名前公開版)では、これまでどおり良い点も残念な点も正直に書く。

## 2. カタログ無料記事(宣伝用・1日1カテゴリー1記事まで)

エリア別「自分の体験談インデックス」。過去記事の公開型スタイルをここで活かす。

```html
<p>{エリア}で実際に行った店・セラピストの自分用まとめ。体験談は随時追加。</p>

<h3>{エリア駅}</h3>
<ul>
<li><strong>{系統+体型スペック}</strong>(評価: 過激施術{★}/寛容度{★})
<br />→ <a href="{自分の記事URL}">{タイトル}</a></li>
</ul>
<!-- 訪問レコードが増えるたびに <li> を追記して再投稿 -->
```

2026-11-10追記: 上の「再投稿」は、既存のカタログ記事を編集して追記する意味で読む。同じ内容の宣伝記事を新規投稿で増やさない。古い記事を消して同じ日に出し直すこともしない(規約1-9)。カテゴリートップへ上げる編集は1日4記事の枠に入る。

- リンクは同カテゴリー(同都道府県)内のみ(規約1-4)
- 店名は伏せてスペック+評価の一部だけ見せ、詳細は各有料記事へ

## 3. まとめ記事(個別体験談6本到達後に解禁)

```html
<p>自分が実際に行った中から{テーマ}を厳選。</p>
<p><small>※本記事には過去に販売した体験談の内容が含まれます(規約に基づく明記)。</small></p>
<!-- 無料: 選定基準とスペックだけ見せる / 有料: 店名・源氏名・要約再編集版 -->
```

- テーマ例: 「{エリア}で寛容度★4以上だった3人」「圧強テク部門ベスト3」
- 素材は訪問レコードの評価6軸から機械的に抽出できる
- 2026-11-11追記(本人了承。[H-13](15-requirements-history.md#h-13-体験内容起点型の記事から取り入れた点)): 体験の条件でまとめるテーマも使う。例: 「初回で{結果}だった人」「裏OPの追加料金なしだった人」「再訪しない人と理由」。条件は本人の訪問記録にある事実だけで判定し、他人の報告や伝聞で人を足さない。無料部分では選定条件と各人の系統だけを見せ、誰がどの結果かは有料部分で示す
- 「再訪しない人と理由」は、再訪意向と残念ポイントの記録から作る。理由は予約の取りやすさ、好みとの違い、寛容度、費用への満足など、記録にある言葉で書く
- 人を追加するときは既存の記事を編集し、冒頭に更新日と掲載人数を書く。同じテーマの記事を新規投稿で増やさない(規約1-9)。解禁条件は変えない
- 単価は単体より高く(500pt〜)

## 4. 再訪記事

```html
<p>{源氏名を伏せた導入}。初回の体験談はこちら →
<a href="{初回記事URL}">{初回記事URL}</a>(※本記事は再訪レポートです)</p>
<!-- 初回リンク明記は規約1-1の要件。差分中心: 前回との違い/進展/変化 -->
```

- 質問票は差分入力モード(初回レコードを読み込み、変わった点だけ入力)
- 2026-11-10追記: 規約1-1は、再訪記事にも店舗名とセラピスト名を書くよう求めている。単体体験談と同じく有料部分に載せる。差分中心の記事でも省かない

## ノウハウ記事(参考・テンプレート外)

訪問不要の頻度維持枠。用語解説・初心者ガイド・予約術など。
体験レコードに依存しないため本ツールの生成対象外(通常のClaude執筆で足りる)。
