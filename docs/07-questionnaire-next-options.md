## 保存先と意味の条件

| まとまり | 候補の例 | 保存先と使い方 |
|---|---|---|
| 対面で受けた印象 | 自然な雰囲気、華やかな雰囲気、落ち着いた雰囲気 | `ratings.face.note` または `ratings.style.note` のうち、本人が判断した軸へ追記する。性格や実年齢の事実にはしない |
| 会話の量と進み方 | 会話が多かった、会話は少なめ、こちらから話すことが多かった | `ratings.service.note`。会話の量と、それが好みに合ったかを分ける |
| 対応と希望の伝達 | 明るい対応だった、慣れた対応だった、希望する部位を伝えた | 接客または施術の評価メモ。誰が何をしたかを残す |
| 手技と重点部位 | 疲れた部位を重点的にケア、背中を中心にケア、ふくらはぎを中心にケア | `ratings.massage.note`、または実際に起きた段階の `flow.*.checks`。段階を自動で決めない |
| 部屋や香りの観察 | 部屋が清潔に感じられた、照明が控えめだった、香水の香りがした | 気づいた実際の段階の `flow.*.note`。客観的な検査結果や接客の意図にはしない |
| 終了後の出来事 | 帰り支度を急かされなかった、終了後に飲み物あり | `flow.after.checks`。会話の有無は既存のチップを使う |
| 残念だった理由 | 所在地の連絡を催促した、場所を探して迷った、浴室の清掃が気になった、前回より物足りなく感じた | 既存の `flow.downside`。本人が残念に感じた時だけ使い、最良の瞬間へは入れない |

追記前の文章を保持し、星評価や別の段階の選択は変えない。現在の追記操作、重複判定、折りたたみ、段階別の選択を引き継ぐ。同じ表現を別の段階で選んだ場合も、選択と解除は段階ごとに扱う。保存済みの未知のチェック値も保持する。

候補を採用しても、観察と評価を混ぜない。会話が少なかったことから、退屈だった、くつろげたという感想は補わない。提案、説明、選択、支払、実施も別々に扱う。実際のセリフ、数値、出来事や因果を候補語から作らない。

段階が分からない出来事は、部位や手技から段階を推測しない。対応する評価理由や残念ポイントへ意味を保って残せる場合を除き、固定チェックとして選ばない。未選択も、なかった、普通だった、未確認へ読み替えない。

## 表示語の限定と既存値の保持

採用済みの語や既存チップと重なるものは、代表語を使う。会話が弾んだ、パウダー、終了後の会話を別名で増やさない。希望を施術へ反映したことと、希望を伝えたことのように、意味の違うものは残す。

| 元の候補 | 表示や記録で守る範囲 |
|---|---|
| 近さに緊張した | 対面時に緊張したことに限定する。近さが原因とは補わない |
| 希望を確認された | 希望する施術部位の確認に限定する。あらゆる希望の確認へ広げない |
| 入室後に総額を確認 | コースと追加内容を確認して支払ったことに限定する。総額を明示確認したとは補わない |
| 追加料金を先に説明された | 「追加内容と料金の説明があった」と表示し、説明された実際の段階を本人が選ぶ。前回計画の「施術前」という表示案は履歴として残す |
| 後半が駆け足だった | 後半の施術を短く感じたことに限定する。施術速度が速かったという意味とは分ける |
| 香りが強く感じられた | 根拠のある香水の香りに限定する。室内臭や体臭へ広げない |
| 前回より物足りない | 同じ担当者との実体験の比較とし、比較対象と物足りなかった点は本人が補う |

元の候補語、表示語、意味の条件は別々に残す。過去の調査記録や保存済みの値を、新しい表示語へ自動で書き換えない。
